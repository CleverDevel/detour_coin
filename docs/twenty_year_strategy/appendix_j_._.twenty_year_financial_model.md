### 2.3 Ownership Dilution Analysis

**Dilution Timeline:**
```
Year 0 (Deployment):     100.0% ownership
Year 1 (First grants):    42.7% ownership (-57.3% dilution)
Year 5 (Launch):          28.3% ownership (-71.7% dilution from Year 0)
Year 10 (Growth):          9.3% ownership (-90.7% dilution from Year 0)
Year 20 (Maturity):        4.0% ownership (-96.0% dilution from Year 0)
```

**Dilution is Strategic, Not Problematic:**

The ownership percentage decrease is intentional and beneficial:

1. **Founder holdings grow** from 10M → 31.8M tokens (3.18x increase)
2. **Total supply grows** from 10M → 785M tokens (78.5x increase)
3. **Token value increases** dramatically due to utility and scarcity
4. **Wealth increases** despite ownership % decrease

**Example:**
```
Year 0: 10M tokens × $0.01 = $100,000 (100% ownership)
Year 20: 31.8M tokens × $0.78 = $24,800,000 (4.0% ownership)

Wealth Multiplication: 248x
Ownership Decrease: 96%
Result: Massive wealth creation despite dilution
```

The model demonstrates that **absolute token holdings and token value matter far more than ownership percentage** in a utility-driven token economy.

## PART 4: TOKEN VALUATION METHODOLOGIES

### 4.1 Valuation Framework

Token value is derived from three primary methodologies, each providing different perspectives on fair value:

1. **Velocity-Based Valuation** (Transaction Volume Method)
2. **Network Value Method** (Metcalfe's Law / Platform Metrics)
3. **Comparable Analysis** (Similar Token Benchmarking)

Final valuation applies weighted average with premiums for:
- Utility premium (real-world use case)
- Network effects (merchant-customer ecosystem)
- Market sentiment (speculative premium/discount)

### 4.2 Velocity-Based Valuation

**Theory:** Equation of Exchange (MV = PQ)

```
M = Money Supply (DTC Circulating Supply)
V = Velocity (how many times each token is used annually)
P = Price Level (average transaction value)
Q = Quantity (number of transactions)

Rearranged: M = PQ / V

Where:
PQ = Total annual DTC transaction volume
V = Velocity of money
M = Required token float (circulating supply needed)

Therefore:
Token Price = (PQ / V) / Circulating Supply
```

**Velocity Assumptions:**

```
Conservative Scenario: V = 8-12x (tokens turn over 8-12 times per year)
Moderate Scenario: V = 10-14x
Optimistic Scenario: V = 12-16x

Higher velocity = more trading = lower required float = lower token value
Lower velocity = more holding = higher required float = higher token value

For DetourCoin, we assume moderate-to-low velocity due to:
- Merchant incentives to hold (rewards program)
- Customer incentives to hold (appreciation potential)
- Limited secondary market speculation initially
- Utility-first design discourages pure trading

Conservative Velocity Used: 10x
```

### 4.3 Network Value Method

**Theory:** Metcalfe's Law - Network value grows with square of users

```
Network Value ∝ n²

Where n = number of active participants (merchants + customers)

For DetourCoin:
V = k × (Merchants × Avg Customers per Merchant)²

We use modified approach:
V = Base Value × (Merchant Count / 1000)^1.5

Exponent 1.5 (not 2.0) reflects:
- Not all merchants equally connected
- Geographic clustering limits network effects
- Diminishing returns at scale
```

### 7.4 Impermanent Loss Consideration

**What is Impermanent Loss?**

When token prices diverge from your entry point, the value of your LP position can be less than if you'd simply held the tokens. This is "impermanent" because it only becomes real when you withdraw.

**DetourCoin Impermanent Loss Scenarios:**

Scenario 1: Price Doubles
```
Entry: $0.340/DTC
Exit: $0.680/DTC

If you'd held separately:
  14,706 DTC × $0.680 = $10,000
  $5,000 USDC = $5,000
  Total: $15,000

Actual LP value with rebalancing:
  ~10,400 DTC × $0.680 = $7,072
  ~$7,072 USDC = $7,072
  Total: $14,144

Impermanent Loss: $856 (5.7%)
Trading Fees Earned: $1,800/year
Net: Positive after 6 months
```

Scenario 2: Price Increases 5x
```
Entry: $0.340/DTC
Exit: $1.700/DTC

If you'd held separately:
  14,706 DTC × $1.700 = $25,000
  $5,000 USDC = $5,000
  Total: $30,000

Actual LP value:
  ~6,550 DTC × $1.700 = $11,135
  ~$11,135 USDC = $11,135
  Total: $22,270

Impermanent Loss: $7,730 (25.8%)
Trading Fees Earned (5 years): ~$50,000
Net: Still positive due to fees
```

**Mitigation Strategy:**

1. **Use Uniswap V3 Concentrated Liquidity**
   - Set narrow price ranges
   - Capture more fees in active range
   - Rebalance monthly as needed

2. **Accept Impermanent Loss as Cost**
   - Primary goal is ecosystem liquidity
   - Fees offset most IL
   - Token appreciation benefits main holdings

3. **Treat LP as Separate Strategy**
   - Don't count LP tokens in main position
   - View as liquidity provision service
   - Measure success by fee generation, not position value
